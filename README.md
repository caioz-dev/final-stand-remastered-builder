# ⚔️ Final Stand: Remastered Builder

Calculadora de builds para o jogo Final Stand: Remastered, desenvolvida por 
iniciativa própria. Permite montar e simular builds completas com validação 
de atributos em tempo real.

## 🚀 Funcionalidades

- Sistema de raças com bônus de atributos distintos
- Distribuição de pontos com validação em tempo real
- Transformações com multiplicadores de status
- Interface interativa e responsiva
- Deploy automático via GitHub Actions

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Actions (CI/CD)
